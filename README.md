# 🚀 CareerPath — Your Career Planning Platform

CareerPath is a web-based platform designed to help students explore career opportunities, learn industry-relevant skills, follow structured learning roadmaps, and prepare for their future careers.

## ✨ Features

- **Career Role Exploration:** Explore career options such as Data Analyst, Software Developer, Frontend Developer, Cloud Engineer, AI Engineer, and Cybersecurity Analyst.
- **Role Details:** Learn about career responsibilities, required skills, education, and salary information.
- **Learning Roadmaps:** Follow step-by-step learning paths from beginner to advanced level.
- **Progress Tracking:** Track learning progress and completed topics.
- **Project Recommendations:** Discover projects based on your selected career role and skill level.
- **Authentication:** Login and registration pages for users.
- **Interview Preparation:** A planned area for practicing technical and HR interview questions.
- **Responsive Design:** Designed to work across different screen sizes.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/suhithavipparthi-sudo/careerpath.git
```

### 2. Open the project

Open the cloned `CareerPath` folder in Visual Studio Code.

### 3. Run the frontend

Open `index.html` using the VS Code Live Server extension.

### 4. Configure the backend

Open a terminal in the `backend` folder and install the dependencies:

```bash
npm install
```

Configure your MySQL database and create a `.env` file using the environment variables required by your backend configuration.

Start the backend using the start command configured in `backend/package.json`, or run:

```bash
node server.js
```

**Note:** The backend requires Node.js and MySQL to be installed and configured. Database credentials should be stored in `.env`, not committed to GitHub.
